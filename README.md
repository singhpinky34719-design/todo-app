# Advanced To-Do List Web App

A modern and responsive To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Edit tasks
- Search tasks
- Filter tasks by status
- Responsive design
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
